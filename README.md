# The Word You'd Delete From the Dictionary

Entry for the make.fun bounty
[u-puan-the-word-you-d-delete-from-the-dictionary-9e774bc2](https://make.fun/c/u-puan-the-word-you-d-delete-from-the-dictionary-9e774bc2).

`main.py` writes one word to `/output/entry.txt`: **fine**.

Erase "fine" and nobody can ever answer "I'm fine" again — the world's
most-used dodge dies, so every "how are you?" demands a real answer.
It also kills the parking ticket. One deletion, two meanings gone.
